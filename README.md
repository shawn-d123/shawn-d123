## 🚀 Stuff I've built

**[SwiftBot](https://github.com/shawn-d123/swiftbot-autonomous-trafficLight-system)** — Java and Raspberry Pi robot that reads traffic light colours with computer vision and drives itself accordingly.

**[Email Calendar Evaluation Pipeline](https://github.com/shawn-d123/email-calendar-evaluation-pipeline)** — Benchmarks rule-based and LLM extraction of events and action items from 1,000 Enron emails, scored on precision, recall and F1.

**[Message Prioritisation Benchmark](https://github.com/shawn-d123/message-prioritisation-benchmark)** — Rule-based, ML and LLM approaches compared for priority classification, including the ambiguous and edge cases.

**[Skybound](https://github.com/shawn-d123/Skybound-unity)** — Unity open-world RPG in C# with persistent saves, combat and enemy AI built on finite state machines.
